# loon-config

Loon 分流配置模板（基于奶思 fmz200 模板定制）。

## 订阅地址

```
https://raw.githubusercontent.com/xxbb678/loon-config/main/loon.conf
```

## 使用前必看

本仓库为**脱敏模板**，下列两处已用占位符替换，需你在本地填回：

1. `[Remote Proxy]` 的节点订阅链接（你自己的机场地址）
2. `[Mitm]` 的 `ca-p12` 证书私钥与 `ca-passphrase` 密码

> 证书私钥与密码**不要**提交到公开仓库：拿到这两样东西就能签发你设备的中间人证书，等于让别人可以窃听你的 HTTPS 流量。

## 注意

导入本文件会覆盖本地配置；在 App 里手动加的节点/分组不会上传，更新订阅时会被清掉。需要保留的分组请先写进本文件。
