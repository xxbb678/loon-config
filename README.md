# loon-private（私人）

个人 Loon 分流配置，含真实订阅地址。

> ⚠️ 仅私人仓库使用，勿转为公开。订阅 URL 泄露 = 别人盗用你的流量。

## 文件

- `loon.conf` — Loon 配置（已删除 MITM 证书私钥）

## 改动说明

基于奶思的 Loon 配置（fmz200/wool_scripts）修改：

1. **新增地区组**：德国节点、法国节点、马来节点
2. **11 个策略组全部补齐 9 个地区组**：香港、台湾、狮城、马来、日本、韩国、美国、德国、法国
3. **筛选器加词边界**（`(?![a-z])`），修复误匹配：
   - `DE-法兰克福Lei**tw**erk` 中的 tw 被 TW_Filter 误捕入台湾组
   - `🇭🇰 香港-Yuu**s**ei` 中的 us 被 US_Filter 误捕入美国组
4. **OT_Filter 补上 HK**，修复香港节点重复出现在「其他节点」
5. **删除 MITM 证书私钥**（`ca-p12` / `ca-passphrase` / `skip-server-cert-verify`）

## 地区组（10）

香港、台湾、狮城、马来、日本、韩国、美国、德国、法国、其他节点

## 已删除内容（如需 HTTPS 解密）

配置 → 点配置文件后的 ⓘ → HTTPS 解密 → 证书 → 生成新的 CA 证书 → 安装并信任
